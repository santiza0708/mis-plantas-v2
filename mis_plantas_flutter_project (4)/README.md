# Mis Plantas - Android MVP (Flutter)

Aplicación móvil personal para el cuidado y seguimiento botánico desarrollada en Flutter bajo Clean Architecture, SQLite local (sin nube), State Management con Riverpod, integración con cámara, notificaciones push locales y análisis de follaje con IA Gemini.

## Requisitos
- Flutter SDK >= 3.3.0
- Android Studio / VS Code
- Emulador o Dispositivo Android

## Instalación y Ejecución
```bash
flutter pub get
flutter run
```
